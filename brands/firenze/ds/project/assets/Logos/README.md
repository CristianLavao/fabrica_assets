Logos oficiales de FIRENZE S.A.S., copiados de los SVG entregables y recoloreados solo con las cinco tintas que aprueba el manual. El sufijo indica la tinta: `verde` es castleton-green, `blanco` es white, `tea` es tea-green, `lapis` es lapis-lazuli y `oxford` es oxford-blue. `firenze-vertical-original` conserva el archivo entregado (sello verde con nombre negro). En las versiones horizontal y vertical, "S.A.S." es texto en Simplo Medium. Dentro de un `<img>`, sin la fuente cargada, se ve con una fuente de reemplazo: cuando importa la fidelidad, inserta el SVG en línea dentro de una página que cargue Simplo.
