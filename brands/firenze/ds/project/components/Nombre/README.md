# Nombre
La palabra FIRENZE con las letras exactas del logotipo (trazados copiados del logo oficial, sin sello, filete ni "S.A.S."). Cada vez que el nombre de la marca aparezca como título o como firma, se pone con esta pieza y nunca se escribe con una fuente.

**Qué aporta quien lo usa:** el fondo y el ancho. La tinta sale de la misma tabla que el componente Logo: `firenze-nombre-verde` sobre blanco, `-blanco` sobre `castleton-green`, `-tea` sobre `oxford-blue`, `-oxford` sobre `tea-green`.

- Úsalo en portadas de propuestas y decks, en encabezados de documentos, en cierres de slides, en el hero de la landing y en el patrón tipográfico.
- Proporción fija de 5.85:1. Escala solo el ancho y deja el alto en automático. Ancho mínimo: 96px.
- Dentro de un texto corrido, la marca se escribe normal ("FIRENZE gestiona…") con la fuente del párrafo. Esta pieza es solo para cuando el nombre funciona como título o como firma.
- Si en la pieza ya está el logo completo, no repitas el nombre suelto al lado.
