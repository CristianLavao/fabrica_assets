# FotoVelo
Una fotografía de marca a sangre, cubierta por un velo plano de color, con un titular encima. Es la forma de poner texto sobre una imagen.

**Qué aporta quien lo usa:** la foto (del grupo Fotografia o propia), la etiqueta y el título.

- Velo de `castleton-green` al 78 %, o de `oxford-blue` al 80 %. Nunca degradados.
- Texto en `white`, con la etiqueta en `tea-green`, abajo a la izquierda y con margen de seguridad.
- Sin bordes redondeados (`radius-none`).
