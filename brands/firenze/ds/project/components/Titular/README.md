# Titular
El bloque de apertura de cualquier pieza: etiqueta (`eyebrow`), título (`display`, `h1` o `h2`), un filete corto de acento y una entradilla (`body-lg`).

**Qué aporta quien lo usa:** la etiqueta (2 o 3 palabras), el título (60 caracteres como máximo) y, si quiere, la entradilla (una o dos frases).

- La etiqueta va en `light-sea-green`, MAYÚSCULAS y Simplo Bold. El título va en `brand-text`.
- El filete mide 64×3px en `light-sea-green` y es el único adorno del bloque.
- Siempre alineado a la izquierda. Sobre fondos oscuros, el título pasa a `white` o `tea-green`.
