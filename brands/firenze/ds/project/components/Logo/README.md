# Logo
El logotipo de FIRENZE en sus versiones horizontal, vertical e isotipo, con la tinta que corresponde a cada fondo.

**Qué aporta quien lo usa:** el fondo (un token de color) y el ancho. La tinta sale de esta tabla:

| Fondo | Archivo |
| --- | --- |
| `castleton-green` | `firenze-*-blanco` |
| `oxford-blue` | `firenze-*-tea` (o `-lapis`, solo para el logo) |
| `white` / `surface` claro | `firenze-*-verde` |
| `tea-green` | `firenze-*-oxford` |

- Formatos horizontales (banner, slides, documentos): versión horizontal.
- Formatos cuadrados y verticales: versión vertical.
- Avatar, sello o marca de agua: isotipo.
- Deja alrededor un área libre igual a la altura de la "F". Ancho mínimo: 120px para el horizontal y 32px para el isotipo.
- No lo coloques sobre una foto sin velo de color.
