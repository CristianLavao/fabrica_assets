# Patron
Filas desplazadas con la palabra FIRENZE repetida, tomadas de la papelería del manual. Es una textura de fondo, no un texto que se lea.

**Qué aporta quien lo usa:** el área que cubre y el par de colores. Usa `firenze-nombre-tea` al 22 % de opacidad sobre `castleton-green`, o `firenze-nombre-verde` al 10 % sobre `surface`.

- Úsalo en reversos de tarjetas, franjas laterales de slides y fondos de portada.
- Que no ocupe más del 20 % de la composición y que nunca quede detrás de un titular o de texto corrido.
- Se construye con el componente Nombre (las letras del logo), nunca escribiendo FIRENZE con una fuente. Las filas pares se desplazan media palabra.
